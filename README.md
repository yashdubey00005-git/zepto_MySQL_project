# zepto_MySQL_project
# 🛒 Zepto E-commerce Data Analysis | MySQL

## 📌 Overview

An end-to-end **SQL data analysis project** using Zepto e-commerce data to analyze **product pricing, discounts, inventory, stock availability, and potential revenue**.

The project was originally based on a PostgreSQL implementation and independently adapted and executed using **MySQL**.

## 🎯 Business Questions

The analysis answers key e-commerce business questions:

* 🏷️ Which products offer the **highest discounts**?
* 📦 Which high-value products are **out of stock**?
* 💰 Which categories have the **highest potential revenue**?
* 🔖 Which expensive products have **minimal discounts**?
* 📊 Which categories offer the **highest average discounts**?
* ⚖️ Which products provide better **value per gram**?
* 📦 How can products be classified by **weight**?
* 🚚 Which categories have the **highest inventory weight**?

## 🧹 Data Preparation

Key data-cleaning and transformation steps:

* Identified and removed **zero-priced products**
* Converted product prices from **paise to INR**
* Analyzed products appearing under **multiple SKUs**
* Checked product categories and **stock availability**
* Handled calculations for inventory and product-level metrics

## 📊 Key Analysis

| Analysis                              | Business Purpose                     |
